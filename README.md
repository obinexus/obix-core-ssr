# obix-core-ssr

> Previous name: `@obinexusltd/obix-core-ssr` — OBIX packages are named without an npm scope since decision D-102 (2026-09-29); the package, its version and its exports are unchanged.

**The SSR projection — DOM-free `renderToString`.**

```bash
npm install obix-core-ssr
```

## API

| Export | Level 0 |
|---|---|
| `renderToString(artifact, { state?, props? })` | ✅ returns an HTML string |
| `renderToStream()` | ❌ throws `UnsupportedFeatureError` (Level 1) — never a silent no-op |

Renders from `artifact.render(state, props)` when present, otherwise walks the
`artifact.template` descriptor. The scope token (from `obix-core-spec.createScopeToken`
via `artifact.style.token`) is applied as `data-obix-scope`.

## Purity (Problem 14)

This package **structurally cannot** be DOM-coupled:

- its only dependencies are `obix-core-spec` and `obix-core-ir`;
- it may not depend on `obix-driver-dom` or `obix-core-reactive`;
- `npm run check:purity` imports it in a fresh process where every browser global is a trap (any read fails), and bundles its static import
  graph for a neutral platform to list every Node built-in it reaches (none); `npm run check:graph` enforces the dependency direction;
- `tests/headless/ssr.test.mjs` renders a compiled component through `renderToString` under the same traps. `renderToStream` throws
  `UnsupportedFeatureError` (Level 1): there is no streaming, and no hydration.

## Dependency role

`obix-core-spec` + `obix-core-ir`. A leaf on the server side.

## Level 0 status

✅ `renderToString`. Full SSR (hydration markers, streaming, slot/loop output) is
deferred to Level 1.

## Architecture role

`obix-core-ssr` is a **lower-level core package**: an implementation building block of OBIX; applications normally reach OBIX through the umbrella `obix`, and install this package directly only for what it alone provides.

The architecture of OBIX — the package families and which packages are public API — is indexed in the umbrella: [docs/architecture.md](https://github.com/obinexus/obix/blob/main/docs/architecture.md).
